## Monthly Focus

Moving from Excel's cell-by-cell formulas into querying entire
databases directly. The core shift this month: Excel formulas ask
"what does this cell contain." SQL queries ask "what does this
entire table tell me." Every SUMIFS and COUNTIFS instinct from
Month 2 carries over SQL's WHERE and GROUP BY are the same logic,
just operating on data that already lives in a real database instead
of a spreadsheet.
