## Monthly Focus

Moving from formula fluency into formula auditing. Month 1 built the foundation, this month is about testing that foundation against AI.
Every SUMIFS, every COUNTIFS, every cleaned dataset gets run through Copilot first, then checked line by line. The goal is not to get AI to do the work faster.
The goal is to get fast enough at spotting where AI's logic breaks, especially on multi-condition formulas and messy real-world data, where AI still gets it 
wrong most often.
